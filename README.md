# Lista de Exercícios em React

Projeto desenvolvido para a disciplina de Desenvolvimento de Aplicações Web Back-end.

## Conteúdo

O projeto contém 7 exercícios em React envolvendo:

- Props
- useState
- Eventos
- Inputs
- Cálculos
- Números aleatórios
- Data e hora

## Tecnologias

- React
- JavaScript
- CSS
- Vite
